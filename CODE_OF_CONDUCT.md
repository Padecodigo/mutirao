# Código de conduta

## Nosso compromisso

Este projeto é feito para pessoas que estão começando. O ambiente aqui precisa
ser o mais acolhedor possível para quem não sabe — porque é exatamente para elas
que estamos construindo.

## Esperado de todos

- Paciência com perguntas iniciantes. "Isso está na documentação" não é resposta.
- Crítica ao código e às ideias, nunca à pessoa.
- Português claro. Se usar termo técnico, explique em cinco palavras.
- Crédito a quem contribuiu.
- Discrição: nunca publique dados, chaves ou prints de outra pessoa.

## Não tolerado

- Desprezo por quem está aprendendo ("é só ler", "todo mundo sabe").
- Assédio, discriminação, ataques pessoais.
- Publicar credenciais, dados pessoais ou conteúdo privado de terceiros.
- Usar as issues para divulgar golpe, automação de conta ou venda de chaves.

## Escopo

Vale para issues, PRs, discussões, commits e qualquer espaço do projeto.

## Aplicação

Problemas podem ser relatados aos mantenedores. Medidas vão de conversa privada
a remoção do espaço, conforme gravidade e reincidência. Relatos são tratados
com confidencialidade.

# As palavras que vão aparecer

Você não precisa decorar nada. Mas quando a IA usar uma dessas palavras, é isso
que ela quer dizer. Volte aqui sempre que esquecer.

---

## Do dia a dia

**Terminal**
Aquela janela preta onde você digita comandos em vez de clicar. É o único lugar
onde o Mutirão vive.

**Pasta / diretório**
A mesma coisa que uma pasta no seu computador. "Estar na pasta do projeto"
significa que os comandos que você digita afetam aquele projeto.

**Repositório (repo)**
A pasta do projeto + todo o histórico de mudanças. Como um Google Docs com
"histórico de versões", mas para arquivos de código.

**Commit**
Uma foto do projeto num momento: "foi até aqui, com estas mudanças". Se algo
der errado depois, dá para voltar a essa foto.

**Branch**
Uma linha do tempo paralela. Você testa uma mudança sem mexer no projeto
principal. Se der certo, junta; se não, descarta.

**Worktree**
Uma cópia extra do projeto no disco, ligada à mesma história. É assim que dois
agentes trabalham ao mesmo tempo sem se atropelar.

**Merge**
Juntar uma branch na outra.

**Deploy / publicar**
Colocar o projeto na internet, num endereço que qualquer pessoa acessa.

**Build**
Montar a versão final do projeto (juntar arquivos, otimizar). Se o build falha,
não publica.

## Da parte que dá medo

**API**
Uma tomada que um programa oferece para outro programa conversar com ele.
Quando você paga com cartão, o site "chama a API do Stripe" — é o site pedindo
para o Stripe cobrar. Você nunca vê, mas acontece.

**Chave de API (ou token)**
A senha que o seu programa usa para provar para a API que é você. **É o que mais
vaza.** No Mutirão, vive no cofre, nunca no código.

**Variável de ambiente**
Um lugar na memória do programa onde se guarda a chave, em vez de escrever a
chave no arquivo. É como entregar a senha na mão na hora de entrar, em vez de
deixar escrita na porta.

**Cofre (vault)**
O programa que guarda as chaves criptografadas: 1Password, Bitwarden, etc. É
onde a verdade mora.

**Webhook**
Um aviso que o serviço manda para o seu sistema quando algo acontece: "o
pagamento foi aprovado". É como o restaurante te ligando quando o pedido sai,
em vez de você ficar perguntando.

**Banco de dados**
Onde as informações ficam guardadas de verdade: pedidos, clientes, produtos.

**Frontend / Backend**
Frontend é o que aparece na tela. Backend é o que roda no servidor, onde a
pessoa não vê (e onde ficam as chaves).

**Servidor**
Um computador ligado 24h que responde às pessoas na internet.

**Localhost**
"Este computador". `http://localhost:3000` é o seu projeto rodando no seu
computador, sem internet no meio.

**Prompt injection**
Quando alguém esconde uma instrução dentro de um texto (um comentário, um
e-mail) para enganar a IA. É por isso que a IA não tem permissão de ler o cofre.

**CI (integração contínua)**
Um robô que roda os testes sozinho a cada mudança. Aquele ✔ verde no GitHub.

---

## Regra prática

Se a IA disser uma palavra destas e você não entender, responda simplesmente:

> "Não entendi. Me explica como se eu tivesse 10 anos."

Ela foi instruída a fazer isso. Não é vergonha — é o trabalho dela.
